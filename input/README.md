# Реестр железнодорожных станций

`rail_station_treatment_registry.csv` — реестр станций Москвы и Московской
области для Python, R и QGIS (разделитель `;`, UTF-8 с BOM). Пересобрать его
можно командой `python scripts/build_station_registry.py` из папки проекта.
Большая база фирм для этого не нужна. Скрипт не изменяет ваш
`rail_stations_verified.csv`: он использует его лишь для сверки координат.

Источники: [Wikidata P127](https://www.wikidata.org/wiki/Property:P127) для
станций, закреплённых за МЖД,
[P81](https://www.wikidata.org/wiki/Property:P81) для физического направления,
[P1192](https://www.wikidata.org/wiki/Property:P1192) для обслуживающей линии
МЦД, [P1619](https://www.wikidata.org/wiki/Property:P1619) для открытия самой
станции и `mcd_line_launches.csv` для дат запуска D1–D4. Включены радиальные
направления МЖД, Большое кольцо и Ленинградское направление ОЖД (оно нужно
для D3). Географический фильтр — тот же прямоугольник, что для фирм:
`(54.20, 35.10, 57.05, 40.30)` в порядке юг, запад, север, восток, после
чего станции фильтруются по сохранённым полигонам Москвы и области из
[geoBoundaries](https://www.geoboundaries.org/api.html) в файле
`moscow_moscow_oblast_boundary.geojson` (границы 2017 года). Недостающие в
Wikidata станции из вашего OSM-файла также сохранены, но не получили
выдуманную линию или дату. Реестр широко покрывает станции региона, но пока
не является доказательством полноты всех действующих пассажирских станций.

Основные столбцы:

- `station_id`, `station_name`, `lon`, `lat`, `source_url` — станция, координаты
  и прямая ссылка на карточку источника;
- `rail_corridor_id`, `corridor_name`, `railway`, `corridor_qids` — физическое
  направление и МЖД/ОЖД; `corridor_id` — кластер для анализа: D1–D4 для
  treated, физическое направление для контроля;
- `mcd_line`, `mcd_lines` — одна обслуживающая линия или полный набор для
  пересадочных станций; пусто, если сервис МЦД не найден;
- `treatment_date` — дата, когда станция стала частью МЦД; пусто у кандидатов
  в контроль и у сомнительных поздно открытых станций. `line_launch_date` и
  `treatment_date_quality` показывают, как получена дата;
- `opening_date`, `opening_date_precision`, `baseline_operating` — дата
  открытия именно станции и признак работы до начала панели (2014);
- `treatment_group`, `review_status`, `did_eligible_candidate` — статус
  treatment/контроля и консервативный фильтр для демонстрационного DiD.

Реестр содержит **764 станции** на момент его сборки: 147 с найденным сервисом
D1–D4, 524 кандидата в контроль с привязкой Wikidata и 93 станции с
неустановленным направлением или только в OSM. Для станций МЖД на ветках вне
списка радиальных линий сохраняются исходные QID и название линии; это не
считается автоматически чистым контролем. Отсутствие P1192, особенно на
коридоре МЦД, **не доказывает**, что там никогда не было МЦД. Поэтому
большинство таких строк остаётся исключённым. Для учебного анализа дополнительно
включены в контроль станции Казанского направления, станции Рязанского
направления восточнее D3 (`lon > 38.3`) и пять отдельных пригородных веток:
Мытищи—Фрязево, Подлипки—Фрязино, Софрино—Красноармейск,
Голицыно—Звенигород и Реутов—Балашиха. В реестре они помечены
`review_status=analysis_control_*`; это явное аналитическое допущение,
а не подтверждение статуса каждой станции. Итого сейчас 141 контрольная
станция с `did_eligible_candidate=1` (53 прежние + 88 добавленных).
При пересборке Wikidata числа могут измениться.

`did_eligible_candidate=1` — только уже работавшие до 2014 года станции с
однозначной когортой, без выявленного совпадения одной OSM-точки с разными
станциями. Это **не ручная верификация**. Перед публикационной оценкой
проверьте историю и расположение станций, маршрут МЦД, закрытия и переносы.
Станции, открытые после запуска линии, не получают задним числом дату её
запуска: при точной дате открытия используется она, иначе дата treatment
остаётся пустой.

Большая база RFSD скачивается в `input/RFSD_hf/` автоматически. Дома АИС ФРТ,
если нужны, положите в `input/houses.csv`; их обработка выключена по умолчанию.
